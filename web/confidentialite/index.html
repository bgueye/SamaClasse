SamaClasse

Politique de confidentialité

Mise à jour le 21 novembre 2026.

SamaClasse est une application gratuite qui présente le programme scolaire du Sénégal : chapitres, leçons et exercices corrigés. Cette page explique quelles données elle enregistre, pourquoi, et comment les supprimer. Elle est conçue par Bocar Gueye, qui est responsable de ces données.

Sans compte : aucune donnée personnelle

Lire les leçons et faire les exercices ne demande aucun compte. Dans ce cas, SamaClasse n’enregistre aucune donnée personnelle sur ses serveurs. Ce que l’élève écrit dans les exercices reste sur son téléphone et n’est jamais envoyé.

Sur le téléphone seulement, l’application garde :

  • une copie des leçons publiées, pour les lire sans connexion ;
  • la classe choisie et la dernière leçon ouverte, pour reprendre la lecture.

Signaler une erreur. Si un lecteur signale une erreur dans une leçon, nous recevons la leçon ou l’exercice concerné, le motif choisi et, s’il en écrit une, sa précision. Aucun nom, compte ni appareil n’est gardé avec le signalement. Pour éviter les envois en masse, une empreinte de l’adresse IP est gardée une heure, puis effacée. Les signalements sont lus par les rédacteurs, pour corriger les leçons.

Avec un compte parent

Un compte facultatif permet à un parent de créer le profil de ses enfants et de suivre leur travail. Seul le parent a un compte : les enfants n’ont ni adresse e-mail ni mot de passe. Nous enregistrons alors :

  • l’adresse e-mail du parent, pour la connexion par code envoyé par e-mail ;
  • le prénom et la classe de chaque enfant, et rien d’autre sur lui ;
  • quand un enfant utilise son profil sur un téléphone : les leçons qu’il ouvre (avec la date) et ses résultats aux exercices (réussi ou non, le score, la date).

Jamais ce que l’enfant écrit. Seuls le résultat et le score partent ; les réponses rédigées restent sur le téléphone.

Le parent peut lier le téléphone de chaque enfant à son profil, avec un code à usage unique affiché sur son propre téléphone. Le téléphone de l’enfant reçoit alors un identifiant technique anonyme (sans adresse e-mail, sans nom, sans numéro de téléphone). Cet identifiant lui permet seulement d’envoyer les leçons lues et les résultats de cet enfant. Nous enregistrons aussi le type d’appareil (par exemple « Android ») et la date de la liaison, pour que le parent reconnaisse ses téléphones. Le parent peut délier un téléphone à tout moment : l’identifiant est alors supprimé.

Ces informations servent uniquement à afficher au parent le suivi de ses enfants. Elles ne sont visibles que depuis son compte. Elles ne sont ni vendues, ni louées, ni utilisées pour de la publicité. L’application ne contient ni publicité ni outil de mesure d’audience.

Rédacteurs

Les personnes chargées de vérifier les leçons (rédacteurs) ont un compte de la même façon. Quand un rédacteur vérifie un point d’une leçon, son compte, la date et sa réponse sont gardés, pour savoir comment chaque leçon a été vérifiée avant sa publication.

Où sont les données

Les données des comptes sont hébergées par Supabase, dans un centre de données situé à Paris (Union européenne). Les échanges entre l’application et les serveurs sont chiffrés (HTTPS). L’accès aux données est protégé par des règles qui ne laissent chaque parent lire que les informations de ses propres enfants. Les e-mails de connexion sont envoyés par un prestataire d’envoi d’e-mails, qui ne reçoit que l’adresse et le code.

Durée de conservation et suppression

Les données d’un compte sont gardées tant que le compte existe. Le parent peut à tout moment :

  • modifier ou supprimer le profil d’un enfant, depuis l’espace parents ;
  • supprimer son compte, depuis l’espace parents (« Supprimer mon compte ») ou sur demande : voir Supprimer votre compte.

Supprimer le compte supprime aussi les profils des enfants, les leçons lues et les résultats, et délie les téléphones des enfants. Pour un rédacteur, les points de leçons qu’il a vérifiés restent, mais sans son nom.

Vos droits

Vous pouvez demander à consulter, corriger ou supprimer les données vous concernant en écrivant à contact@samaclasse.app. Vous pouvez aussi saisir l’autorité de protection des données de votre pays (au Sénégal, la Commission de protection des données personnelles).

Contact

Pour toute question sur cette politique : contact@samaclasse.app.
